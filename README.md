# Bakery Sales Analysis – Excel

## 📊 Project Overview

This project analyzes bakery sales data using Microsoft Excel to identify sales trends, product performance, discount impact, and overall business performance.

The project includes data cleaning, analysis using Excel formulas, PivotTables, and an interactive dashboard.

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- PivotTables
- Data Analysis
- Dashboard Creation
- Sales & Discount Analysis
- Data Visualization

## 📁 Project Contents

- `Bakery_Sales_Project_Data.xlsm` – Complete Excel project containing the dataset, analysis, PivotTables, and dashboard.

## 🔍 Analysis Performed

- Sales performance analysis
- Monthly sales analysis
- Product-wise sales analysis
- Discount analysis
- Quantity and revenue analysis
- PivotTable-based analysis
- Dashboard and KPI visualization

## 📈 Dashboard

The Excel dashboard provides a visual summary of bakery sales performance using KPIs, charts, and interactive analysis.
